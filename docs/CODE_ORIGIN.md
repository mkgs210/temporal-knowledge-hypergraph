# Code provenance and dependency boundaries

Our submission method consists of the native divisive hierarchy, counted quotient, persisted updater, validators, exact-cache readers, BM25/incidence search and paired evaluation in `src/tkh/`. No participant implementation is vendored, imported, invoked or required by the submission entry points. Earlier public solutions were inspected and run for comparison during development. Their repositories and execution adapters are excluded from the current submission; this does not establish independent conceptual novelty.

A local read-only source audit compared 103 then-current Python files against 233 Python files in available cached participant repositories. After removing comments/whitespace, no contiguous exact block of at least 30 significant tokens (including identifiers/literals) matched. The audit found explicit participant-execution adapters in the old reference scripts; those were excluded. The 32-module conservative old closure was further reduced to the current standalone source. Frozen vectors were generated by our own model adapter before reference subprocesses; no participant-produced features or partitions are used to construct this method.

Those historical counts describe the older source snapshot, not a fresh token-overlap audit of the current finishing changes. This supports absence of substantial literal copying from the inspected snapshots. It cannot prove independent conceptual origin, detect every renamed/restructured implementation, or establish global novelty. Previously inspecting public approaches is not concealed. Our algorithm combines cited established primitives and is not claimed as a novel state-of-the-art algorithm.

## Standard dependencies and assets

- **Current CPU path:** Sentence Transformers `all-MiniLM-L6-v2`, revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41`; https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2 . Vectors are calculated from raw own names on CPU and cached by exact text. The E5/Nemotron assets listed below are historical replay inputs, not dependencies of the new build.
- **Mt-KaHyPar**, pinned library: native connectivity/KM1 partitioning/refinement. We call its public API and implement our own staging, temporal constraints and accounting. Gottesbüren et al., ALENEX 2021: https://doi.org/10.1137/1.9781611976472.2 . Library: https://github.com/kahypar/mt-kahypar .
- **BM25S** and **PyStemmer**: lexical scoring and English stemming. https://github.com/xhluca/bm25s .
- **NumPy/SciPy/scikit-learn**, JSON Schema and Matplotlib/ReportLab: standard numerical, evaluation, validation and reporting libraries. No package source is copied into the repository; versions are pinned.
- **Historical only — E5-base-v2**: own unit-vector outputs, revision `f52bf8ec8c7124536f0efb74aca902b2995e5bcd`; https://huggingface.co/intfloat/e5-base-v2 . These assets are not included in the current CPU release.
- **Historical only — Nemotron-3-Embed-8B-BF16**: previously computed own 4096-dimensional independent-family vectors, revision `d1f2f25730bbd775b99b29185134bc86653bf2d1`; https://huggingface.co/nvidia/Nemotron-3-Embed-8B-BF16 . No model weights are bundled or loaded during replay. The evaluator was inspected during development.
- **Scientific Agent Skills**, procedural writing/review/visualization guidance: Kassis et al. (2026), https://doi.org/10.48550/arXiv.2609.00065 . Use is disclosed, not evidence of validity.

The supplied data and the official assessment retain their original provenance. This preparation does not assert rights to relicense them or third-party models/libraries. Model outputs include provenance and hashes; pretrained weights and cloned participant repositories are excluded.

The new component-control runner and deterministic hierarchy illustration use existing public library APIs and our own saved data. No external implementation or new dependency is copied. Current release documentation is allowlisted; historical research notes remain in the worktree and are excluded from the submission ZIP.
