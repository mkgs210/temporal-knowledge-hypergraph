# Reproduction scope — current CPU study

README.md contains the authoritative single command: `make all`. Use Python 3.12,
Linux x86_64 and requirements-cpu.lock in an isolated environment. A first run
fetches the pinned all-MiniLM-L6-v2 checkpoint and computes own-surface-form vectors
on CPU; no GPU, E5 assets or participant repository is required.

`make all` executes real initial native construction and four checkpoint-based
updates, structural validation, frozen matched predictions, citation/null
coherence, deletion rebuilds, chronological audits, two component controls,
annotation/checking, the saved hierarchy illustration, report generation and ZIP
packaging. Component controls reuse this run's authenticated vectors. They do not
invoke a model or transfer main-method label judgments.

The complete command always replays exact archived annotation/checker requests
from annotations/nvidia_labels.tar.gz, without new LLM calls. Altering partitions, evidence, prompts or settings
invalidates those responses. A keyless reproduction therefore checks the same
scientific artifact, not independent repeated model judgments. Gemini is disabled
for final checking. make offline omits T5 and is explicitly incomplete for labels.

Prediction locks authenticate files before reference answers are opened. They do
not turn development questions into an untouched test. The same qualifications
apply to the controlled comparisons and reported conditional intervals.

Evidence: results/verification.json and results/verification logs. A real model
run from an extracted submission was performed; unit/integration tests separately
mock remote transport or neural inference for speed. Their success must never be
substituted for that real-run evidence. Current verification records name the
commands and measured source/artifact checks; there is no promise of
byte-identical PDFs across arbitrary software or font environments.

Publication years are retrospective cutoffs, not original ingestion timestamps.
Stable identities, hard caps and exact endpoint conservation are executable
properties. Scientific topic quality and downstream benefit remain empirical.
A valid negative retrieval result is still an evaluation result.
